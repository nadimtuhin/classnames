# Contributing

Contributions are welcome! Please open an issue or pull request.

## Getting Started

1. Fork the repo and clone locally
2. Make your changes in a feature branch
3. Add or update tests if applicable
4. Open a pull request against `main`

## Code Style

Follow existing PHP conventions in the codebase. Keep functions simple and well-documented.

## Reporting Bugs

Open a [GitHub issue](https://github.com/nadimtuhin/classnames/issues) with a clear description and a minimal reproduction case.
